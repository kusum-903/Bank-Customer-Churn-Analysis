# Bank Customer Churn Analysis

## Project Overview

This project analyzes bank customer data to identify customer churn patterns and understand the factors associated with customer attrition.

The project follows an end-to-end data analysis workflow:

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

---

## Tools & Technologies

- Python
- Pandas
- SQL
- Power BI
- Power Query
- DAX
- Data Visualization

### Business Insights

Identifies high-risk customer segments and provides actionable recommendations.

---

## Key Insights

- Overall customer churn rate is **20.37%**.
- Germany has the highest churn rate at **32.44%**.
- Customers with balances below **50K** have the highest churn rate at **34.67%**.
- Inactive customers have a higher churn rate than active customers.
- Customers with **4 products** show the highest churn rate.
- Salary appears to have relatively minimal impact on churn.

---

## Business Recommendations

- Prioritize retention campaigns for customers with balances below 50K.
- Target high-risk customers in Germany with personalized retention strategies.
- Re-engage inactive customers through targeted offers and communication.
- Investigate why customers with 4 products have a high churn rate.
- Focus retention efforts on high-risk age and credit-score segments.
